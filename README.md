# 瘋疾自投醫院（《東華報》1925-11-28 第7版，澳洲國家圖書館） / Feng ji zi tou yi yuan [A Man Admits Himself to Hospital]: Transcription Dataset

《東華報》1925-11-28 刊載的〈瘋疾自投醫院〉。原報記雪梨警方接到一名疑有瘋疾的華人到埠的消息，在菜園找尋，後知其已自行入防疫醫院。末欄續於同版下一區；同頁另篇〈瘋疾潛來雪梨〉可能為同一事件的先前報導。

Feng ji zi tou yi yuan [A Man Admits Himself to Hospital] appeared in Tung Wah Times (1925-11-28). The paper reports that police in Sydney looked for a Chinese man said to be mentally unwell and then learned that he had already presented himself at a hospital. The final lines continue in the next block of the same page.

TXT, JSON and TEI XML cover the complete separately headed article, comprising the heading and 7 source columns on page 7. An independent image reading was compared with the first transcription. Source-image adjudication adopted 3 changes and retained unresolved readings.

## 方法與覆核 / Methods and review

由 AI 依固定館方影像逐欄讀字，保留原字、版面與疑讀。照錄原題、時代用字與原欄次。疑讀按欄記在 JSON。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant transcribed the fixed source images column by column, preserving source forms, layout and uncertain readings. Headings, historical terminology and source column order are preserved. Uncertainties are recorded by column. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
